# 书签

收藏常用的博客和知识库文件，快速访问。

[→ 打开收藏](/bookmarks)

## 添加书签

在**博客预览页**或**知识库**中，点击标题旁的 Bookmark 图标：

- 空心 Bookmark → 点击 → 实心绿色 = 已收藏
- 再次点击 → 取消收藏

[→ 去一篇博客试试](/blog)

## 书签列表

侧边栏「收纳」→「收藏」进入书签页面。按收藏时间倒序排列：

- 每条显示类型图标（博客/知识库）+ 标题 + 收藏日期
- hover 显示删除按钮
- 点击 → 跳转到原内容

## 使用场景

- **参考资料**: 收藏常用的部署文档、配置模板
- **写作灵感**: 收藏想引用的博客和知识片段
- **快速访问**: 替代浏览历史，更精准
