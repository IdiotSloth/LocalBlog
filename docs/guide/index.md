# 欢迎来到精炼书房

Local Blog KB 是你的离线优先个人知识中枢。所有数据存储在你自己的电脑上，零云端依赖。

## 核心理念

- **写作**: Markdown 博客编辑器，支持 [[双向链接]]、![[内容嵌入]]、Callout 块。memos 风格卡片 Feed + 无限滚动
- **收纳**: 知识库卡片画布，点击系统程序打开文件（不内嵌预览），拖入即导入，文件夹侧栏 + 排序搜索
- **思考**: 白板（YouTrack 风格）自由放置 6 种卡片，连线组织知识网。双向同步
- **AI 助手**: 内置 RAG 问答，基于你的知识库内容回答
- **国风主题**: 8 套主题（墨砚/茶竹/夜灯/宣纸/青瓷 + 系统/亮色/暗色），350ms 全局过渡

## 快速入门

1. **写博客**: 点击侧边栏「博客」→「新建」，或用 `Ctrl+N`
2. **导入知识**: 拖文件到知识库页面 → 卡片网格出现（Pogget 风格：不搬运文件，直接呈现）
3. **建立链接**: 在博客中输入 `[[` 触发 wikilink 建议
4. **便签**: 在「便签」页面自由拖放方形卡片，双击画布创建新便签，粘贴图片到便签中
5. **白板**: 在「思考」→「白板」中自由排列想法卡片，连线标注关联/依赖/引用
