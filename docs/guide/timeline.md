# 时间轴

按时间浏览你的知识生长过程——博客和知识库文件按创建时间倒序排列。

[→ 打开时间轴](/timeline)

## 时间轴视图

侧边栏「思考」→「时间轴」进入：

- **垂直时间轴**: 左侧竖线 + 右侧内容卡片
- **月份分组**: 按月分隔，每月有圆形标记
- **类型过滤**: 全部 / 博客 / 知识库 三个按钮
- **混合排列**: 博客和知识文件按时间混合展示

## 卡片信息

每张卡片显示：

- 类型图标（博客蓝色 / 知识库绿色）+ 类型标签
- 标题
- 创建日期

点击卡片 → 跳转到博客详情或知识库页面。

## 使用场景

- **回顾**: 看看上个月写了什么、导入了什么
- **发现**: 找到遗忘的旧内容
- **时间线**: 了解知识积累的过程
