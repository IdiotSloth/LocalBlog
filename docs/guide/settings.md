# 设置

应用的配置中心。侧边栏底部「设置」进入。

[→ 打开设置](/settings)

## 主题

8 套主题可选：

- **跟随系统**: 自动切换墨砚/宣纸
- **亮色**: 传统亮色模式
- **暗色**: 传统暗色模式
- **墨砚** (默认暗色): 端砚灰底 + 赭石铜赤 — 沉稳中性
- **茶竹**: 深烘茶棕底 + 干竹灰绿 — 有生命力的暗色
- **夜灯**: 暖炭底 + 旧黄铜 — 稳重沉静
- **宣纸** (默认亮色): 生宣冷白底 + 靛蓝 — 清爽有精神
- **青瓷**: 瓷胎白底 + 青釉玉色 — 唯一冷调亮色

全局 350ms 主题切换过渡。

## 背景图片

选择图片作为全局背景（花笺风格半透明覆盖层）：

- 选择 PNG/JPG/WebP 图片文件
- 不透明度滑块（0.85-0.98）
- `#root::before` 伪元素实现
- 加载失败自动回退纯色 + toast
- 仅本地存储，不上传
- 文件路径穿越防护（realpath + symlink 检测 + 50MB 上限）

## 剪贴板监听

控制剪贴板自动记录（默认关闭）：

- 开启后每 500ms 轮询系统剪贴板
- 自动记录文本和 HTML 内容
- 手机号/身份证/邮箱自动打码
- 便签页顶部剪贴板区查看历史

## AI 对话

配置 LLM 以启用 AI 助手：

- 选择服务商（OpenAI / Anthropic / DeepSeek / Ollama）
- 填写 API Key（仅存本地，不上传）
- 可选自定义模型和 API 地址

[→ AI 使用指南](/guide) 然后点击「AI 助手」

## MCP Server

MCP Server 通过 stdio 模式连接 Claude Code / VS Code：

- **stdio 模式**: `npm run mcp` — Claude Code / VS Code 本地直连

## 数据导出

点击「导出 Markdown」按钮：

- 所有博客导出为 .md 文件（YAML frontmatter + 正文）
- wikilink `[[...]]` 自动降级为 `[标题](文件名.md)`
- 知识库文件原样复制到 Export/knowledge/
- 生成 index.md 目录

输出位置: `workspace/Export/`
