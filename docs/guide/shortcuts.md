# 快捷键

## 全局

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+N` | 新建博客 |
| `Ctrl+O` | 快速切换 (标题搜索) |
| `Ctrl+K` | 全局搜索 |
| `Ctrl+B` | 折叠/展开侧边栏 |

## 编辑器

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+S` | 保存 |
| `Ctrl+J` | AI 指令面板 |
| `Ctrl+Shift+1~4` | 插入 Callout (info/success/warning/danger) |
| `Ctrl+\\` | 分屏 MD 预览 |

## 搜索

| 快捷键 | 功能 |
|--------|------|
| `Escape` | 关闭搜索/对话框 |
| `Enter` | 打开选中结果 |
| `↑↓` | 导航搜索结果 |

## 日历

| 操作 | 功能 |
|------|------|
| `← →` | 切换月份 (按钮) |
| 点击月份标签 | 12 格快速选择 |
| 点击"今天" | 跳回当前月份 |
