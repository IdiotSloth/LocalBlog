# 白板

白板是"精炼书房"的**中央桌面**——无限画布上自由放置想法、任务、参考卡片，用连线组织你的知识网。

[→ 打开白板](/whiteboards)

## 核心概念

白板 = **无限画布** + **卡片** + **连线**。你可以在画布上任意放置、拖拽、组织你的知识资产。

## 画布交互

- **无限画布**: 可缩放、平移，无边界限制
- **点阵背景**: 辅助对齐
- **小地图**: 右下角缩略图，快速定位
- **控件**: 缩放按钮 + 适应视图

## 卡片类型 (6 种)

| 类型 | 图标 | 说明 | 双击行为 |
|------|------|------|----------|
| 💡 想法 | 彩色边框 | 记录灵感，可转化为博客或便签 | 编辑标题 (quickInput 弹窗) |
| ✅ 任务 | checkbox + 状态 | todo → in_progress → done 三态流转 | 点击切换状态 |
| 📝 文本 | 简洁文本 | 画布上的标题/标签，用于分区 | 编辑文本 |
| 📄 博客链接 | FileEdit 图标 | 博客卡片链接，双击可编辑标题（同步更新博客） | 导航到博客 |
| 📂 KB 链接 | Library 图标 | 知识库文件链接，可从 KB 页拖入 | 导航到知识库 |
| 🔖 书签链接 | Bookmark 图标 | 书签卡片链接 | 导航到书签 |

## 核心操作

### 创建卡片
- 工具栏 `+ 想法` / `+ 任务` / `+ 文本` / `+ 博客` / `+ KB` / `+ 书签`
- 空白处双击 → 创建想法卡片
- 从知识库拖入文件卡片 → 自动创建 KB 链接卡片

### 连线
- 从卡片边缘拖出连线到另一张卡片 → 弹出 3 选 1 浮层
- 连线类型: 关联 / 依赖 / 引用
- 删除连线: 选中后 Delete

### 右键菜单
- 右键卡片 → 转为任务 / 转为博客 / 转为便签

### 移动与定位
- 拖拽卡片到任意位置，位置自动保存
- 缩放画布: 鼠标滚轮
- 平移画布: 拖拽空白区域

## 双向同步

白板上的链接卡片与原始内容双向同步：
- 博客标题改了 → 白板卡片自动刷新（EVT_BLOG_REFRESH 事件驱动）
- KB 更新 → 白板卡片自动刷新（EVT_KB_REFRESH 事件驱动）
- 双击博客链接卡片编辑标题 → 源博客标题同步更新

## 使用场景

### 项目规划
想法卡片 + 任务卡片 = 项目看板。用连线标注依赖关系。

### 知识梳理
把相关博客、知识文件卡片放到白板上，用连线标注引用关系 → 知识图谱。比 d3-force 更自由。

[→ 试试: 在白板上规划一个项目](/whiteboards)

### 写作大纲
文本卡片分层排列 → 每张卡片代表一个章节 → 展开为博客系列。

### 会议记录
会议中快速创建想法卡片 → 会后转化为正式文档。
