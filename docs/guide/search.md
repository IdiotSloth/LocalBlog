# 搜索

Local Blog KB 提供全文搜索和语义搜索两种引擎。

## 全局搜索 (Ctrl+K)

按 `Ctrl+K` 打开全局搜索面板 [→ 试试: 按 Ctrl+K]:

- **关键词搜索**: 搜索博客标题和知识库文件名
- **搜索操作符**: 支持 `tag:`, `type:`, `after:`, `before:` 过滤
- **类型过滤**: `type:blog` 只搜博客, `type:knowledge` 只搜知识库

例句:
- `Docker` → 搜索所有内容
- `tag:部署` → 搜索标签为"部署"的内容
- `type:blog after:2026-01-01` → 搜索 2026 年起的博客

## 保存的查询

搜索结果底部有「保存此查询」按钮。保存后，HomePage 会显示已保存查询的快捷标签。

[→ 试试: 搜索后保存一个查询，回到首页看看](/)

## 语义搜索

当 embedding 模型加载后（首次使用 ~120MB 下载），搜索还会包含语义相似度评分。向量相似度和关键词匹配混合排序。

## CJK 中文搜索

中文/日文/韩文搜索使用三层次索引:
- **Unigram** (单字, 权重 0.25)
- **Bigram** (双字, 权重 0.5)
- **Word** (整词, 权重 1.0)

单字搜索也能找到多字词结果。MySQL 模式使用 FULLTEXT + ngram parser。
