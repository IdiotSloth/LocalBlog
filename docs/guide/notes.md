# 便签

便签是快速记录工具。采用自由拖放的方形卡片设计。

[→ 打开便签](/notes)

## NoteCard 便签卡片

每张便签是一张 180×180px 方形卡片：

- **6 种便签纸底色**: 米白/浅黄/浅蓝/浅绿/浅粉/浅紫，基于 `id % 6` 确定性分配（同 ID 永远同色，跨 session 稳定）
- **圆角 4px**（便签是方的，不是圆的）
- **阴影**: 0 1px 3px，hover 加深 + zIndex 提升
- **内容**: line-clamp-4，13px
- **底部**: 创建时间 11px

**操作按钮**（右上角，hover 出现）:
- **复制** (📋): 复制全文到系统剪贴板
- **编辑** (✎): 卡片原地展开 textarea，Ctrl+Enter 保存，Escape 取消
- **全文** (👁): 弹出 modal 显示完整内容

## 自由拖放

- react-draggable 控制位置，`position: absolute` 在画布上自由摆放
- 拖拽后位置自动保存到 localStorage `lbkb_note_positions`
- 刷新页面后位置保持不变
- 双击画布空白区域 → 在双击位置创建新便签
- 拖拽中 z-index 提升，松开即持久化

## 创建便签

- **新建按钮**: 页面顶部 "+" 按钮
- **双击空白**: 在画布上任意位置双击创建
- **inline 输入**: textarea + Enter 保存 / Escape 取消（替代 prompt()）

## 剪贴板区

便签页顶部剪贴板区域：

- **自动收集**: 开启剪贴板监听后，每 2 秒轮询系统剪贴板
- **横向滚动卡片**: 120×80px 小卡片，显示截取文本或图片缩略图
- **点击创建**: 点击剪贴板条目 → 自动创建新便签，内容 = 剪贴内容
- **清空全部**: 一键清除历史

## 图片粘贴 + 拖入

- **Ctrl+V 粘贴图片**: 便签编辑框内粘贴图片 → 保存到 workspace/notes-images/{uuid}.png
- **拖入图片**: 从文件管理器拖入图片到便签画布 → 自动创建新便签并嵌入图片
- **级联删除**: 删除便签时自动清理关联的图片文件

## 便签类型

便签支持多种类型：note (普通) / todo (待办) / schedule (日程)。待办便签可在今日页日历中勾选完成。
