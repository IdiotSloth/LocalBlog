# 便签

便签是快速记录工具。支持便签列表和快捷便签 (Alt+Space) 两种模式。

[→ 打开便签](/notes)

## 快捷便签 (Alt+Space)

按 `Alt+Space` 弹出快捷便签窗口（420×320, 屏幕居中, 置顶, 透明窗口）：

- 写内容 → **Ctrl+Enter** 保存为便签，自动清空
- **Esc** 隐藏窗口，自动保存草稿（跨重启恢复）
- **📌 固定**: 保存为 pinned 便签，保持窗口
- **📋 剪贴板**: 底部按钮弹出剪贴板历史 popover，点击粘贴

透明窗口设计（花笺风格）：`transparent:true` + `backgroundColor:#00000000`，便签浮于桌面。

[→ 试试: 按 Alt+Space]

## 便签列表

侧边栏「便签」进入列表页。支持：

- **快速输入**: 上方输入框即时保存 [→ 试试](/notes)
- **置顶**: 重要便签 pin 到顶部
- **便签类型**: note (普通) / todo (待办) / schedule (日程) / daily (每日) / pinned (固定)

## 剪贴板监听

设置页可开启剪贴板监听（默认关闭）：

- 每 500ms 轮询系统剪贴板
- 捕获文本 + HTML 内容（自动提取纯文本摘要）
- MD5 去重
- 隐私遮蔽：手机号/身份证/邮箱自动打码
- 最多保留 50 条
- 设置表持久化（跨重启保留）

## 每日便签

今日中枢的「今日便签」区域会自动创建/加载当天的 daily note。日历上蓝色圆点标记有每日便签的日期，点击日期切换。

[→ 打开今日中枢](/)

## 日程

在便签列表或日历中创建 schedule 类型的便签，设置日期和时间。日历上绿色圆点标记有日程的日期。
