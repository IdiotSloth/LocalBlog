# 标签页系统

多文档并开，不打断写作流。标签页让你同时打开多个博客/知识库/页面。

## TabBar

顶部搜索栏下方是标签栏：

- **自动捕获**: 点击侧边栏任意入口，自动打开对应标签
- **最多 8 个**: 超出自动关闭最早的标签
- **关闭标签**: hover 显示 × 按钮（今日标签不可关闭）
- **当前标签**: accent-blue 下划线高亮

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+1` ~ `Ctrl+8` | 切换到第 N 个标签 |
| 点击标签 | 切换到该标签 |

## 持久化

标签状态自动保存到 localStorage。下次启动应用时，自动恢复上次打开的标签。

## 使用场景

- **写作时参考**: 左边开博客编辑，右边开参考资料
- **多任务**: 同时管理知识库 + 便签 + 设置
- **快速切换**: Ctrl+1-8 秒切
