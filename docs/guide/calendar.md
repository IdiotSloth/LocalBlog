# 日历

日历集成在今日中枢页面，采用 **Obsidian Calendar 插件风格**——圆点标记 + 点击跳转。

[→ 打开今日中枢](/)

## 视觉设计

### 三圆点系统

每个日期格下方用小圆点标记有无内容：

- **蓝色圆点** (6px, --accent-blue): 这一天有便签 (note)
- **橙色圆点** (6px, #e08b4a): 这一天有待办 (todo)
- **绿色圆点** (6px, --accent-green): 这一天有日程 (schedule)
- **多个圆点并排**: 同时有多种内容
- **无圆点**: 这一天没有记录

一目了然看到哪些日子写了笔记。三种圆点颜色区分内容类型。没有数字角标——圆点更安静。

[→ 试试: 在今日便签写点东西，切到日历看看蓝点](/)

### ISO 周数

日历每行左侧显示 ISO 周数 (W21, W22...)，小字 text-muted。方便按周回顾。

## 导航交互

### 月份切换

- **← → 按钮**: 切换上/下个月
- **月份标签**: 点击"2026 年 5 月" → 弹出 12 格月份快速选择
- **今天按钮**: 一键跳回当前月份（右上角）

### 日期交互

- **今天高亮**: 蓝色加粗字体 + bg-tertiary 背景
- **选中日期**: accent-blue 边框高亮
- **点击日期**: 右侧详情面板显示该日待办 (可勾选) + 便签列表 + 日程列表

## 今日详情面板

点击日期后，右侧面板显示该日详情：

### 待办
在面板顶部添加待办项，存储为 `memoType: 'todo'` 关联到选中日期。勾选完成 → 文本划线变灰。有未完成待办的日期 → 橙色 ●。

### 便签与日程
该日便签和日程列表。空日期显示"当日无记录"。

## 与 Obsidian Calendar 的对比


| 特性 | Obsidian | Local Blog KB |
|------|----------|---------------|
| 每日便签标记 | ● 圆点 | ● 蓝色圆点 |
| 待办标记 | 无内置 | ● 橙色圆点 |
| 日程标记 | 无 | ● 绿色圆点 |
| ISO 周数 | ✅ | ✅ |
| 月份选择器 | 无 | ✅ 12 格快速选择 |
| 点击日期行为 | 打开 daily note | 显示当日详情面板 (待办+便签+日程) |
